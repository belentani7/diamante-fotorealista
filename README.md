# Diamante Fotorrealista

Experimento visual en TypeScript: un diamante de corte brillante renderizado en 3D con iluminacion de estudio, exposicion lineal y texturas procedurales.

## Tecnologias

- **React + Three.js** (via react-three-fiber)
- **TypeScript** estricto
- **Vite** para el desarrollo y build

## Arranque

```bash
npm install
npm run dev
```

## Estructura

| Ruta | Contenido |
|---|---|
| `src/diamond/` | Geometria del diamante, trazado de facetas y corte brillante |
| `src/scene/` | Escena, atmosphere, suelo, exposicion lineal y entorno de estudio |
| `src/ui/` | Overlay de interfaz |
